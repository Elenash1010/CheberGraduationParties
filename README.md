## Что заменить перед рекламным запуском

В content.js собраны программы, цены, фото, контакты и параметры формы. Значения в квадратных скобках автоматически скрываются. Не заменяйте их вымышленными данными.

1. Передайте настоящий логотип: images/logo-cheber.svg, укажите CONTENT.logo. Пока используется обычное текстовое название, без имитации фирменного знака.
2. Добавьте реальные фото. hero.src — images/hero-cheber.webp; programs[0].photo — images/program-garden.webp; programs[1].photo — images/program-school.webp; diningPhoto — images/dining-cheber.webp. Галерея: [{src:'images/territory-01.webp',caption:'Точная подпись'}]. Преимущества: [{src:'images/venue-01.webp',caption:'Подтверждённое преимущество'}]. Заглушки — нейтральные блоки, а не изображения курорта.
3. Заполните обе программы: название, сценарий, includes (список), продолжительность, доступное время, цена на ребёнка, условия для взрослых, меню, минимум участников, дополнительные услуги, условия.
4. Укажите действительные URL privacy и consent, относящиеся к оператору этой формы. Ссылки не выдуманы: до получения документов они скрыты, отправка не работает.
5. Подключите endpoint (HTTPS POST JSON). Ответ только при фактически принятой заявке: HTTP 2xx и {"success":true}. Любой иной результат, включая HTML-ответ, покажет ошибку. Для отдельного домена настройте CORS. На стороне обработчика нужны проверка данных и согласия, ограничение частоты и защита от спама. Контакты не сохраняются в браузере и не отправляются, пока подключение не готово.
6. После подключения проверьте реальную доставку заявки менеджеру. Отправка не означает бронирование.

Поля формы: name, phone, program (garden / school / consult), date, count. Дополнительно передаются consent:true и consentDocument (URL документа); версию документа и серверную проверку задайте при интеграции.

## Перенос на Тильду

Каждый section — самостоятельный блок. Сохраните id секций, диалоги, content.js и app.js; подключите styles.css. Изолируйте стили от глобальных стилей Тильды при встраивании. Форму можно перевести на штатную интеграцию Тильды после проверки документов и реальной доставки.
